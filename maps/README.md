# CARLA Custom Highway & Ditch Scenario (LCC / ISO 26262)

Проект высокоточного окружения трассы первой технической категории (СП 34.13330.2021 / ГОСТ) для тестирования ассистентов удержания в полосе (LCC) и предотвращения съезда в кювет (Road Departure Mitigation) в симуляторе CARLA 0.9.16.

---

## 📁 Структура проекта

```
maps/
├── assets/                  # 3D-модели FBX и дорожная разметка OpenDRIVE

│   ├── generate_ditch_map.py# Комплексный генератор XODR + FBX
│   └── verify_ditch_map.py  # Математическая верификация поперечных уклонов

├── pipeline/                # Скрипты автоматической сборки, кукинга и деплоя
```

## 🚀 Быстрый старт

### 1. Запуск сценария в CARLA
Убедитесь, что сервер CARLA запущен (`CarlaUE4.exe`), затем выполните:
```bash
python test.py
```
*Автомобили Ego и Target автоматически появятся на полосах, спектэйтор займет ракурс за автомобилем, а PhysX зафиксирует высоту $Z = 0.033$ м.*

### 2. Сборка и деплой новой кастомной карты (в 1 команду)
Для сборки нового уровня из `.fbx` и `.xodr` без открытия Unreal Editor:
```powershell
powershell -ExecutionPolicy Bypass -File pipeline/build_and_deploy_map.ps1 -MapName "имя_карты"
```
