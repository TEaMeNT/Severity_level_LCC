### 1.1. Итоговые вердикты HARA по раздельным строкам `1.1.A` / `1.1.B` и `Worst-Case` (ISO 26262-3 / SAE J2980:2023 §5.2.1.5(g), §5.2.2.2 Note 1):
1. **Строка HARA `1.1.A` — Подкласс А (Ограждение слева, $n_A = 189$):** **Класс S1**
   * *Обоснование:* Кумулятивная вероятность травм легкой/средней тяжести среди ДТП P(≥S1 | ДТП) = 98.9% превышает нормативный порог 10.0%.
   * *Точечная оценка и 95% ДИ Клоппера–Пирсона (информационно, SAE J2980 Appendix B §B.1):* $P_A(\ge S2 \mid \text{ДТП}) = 1.6\%$ (95% ДИ: $[0.33\%, 4.57\%]$).
2. **Строка HARA `1.1.B` — Подкласс B (Кювет справа, $n_B = 190$):** **Класс S2**
   * *Обоснование:* Кумулятивная вероятность тяжелых травм среди ДТП P(≥S2 | ДТП) = 12.1% (S3: 2.1%, S2: 10.00%) превышает нормативный порог 10.0%.
   * *Точечная оценка и 95% ДИ Клоппера–Пирсона (информационно, SAE J2980 Appendix B §B.1):* $P_B(\ge S2 \mid \text{ДТП}) = 12.1\%$ (95% ДИ: $[7.83\%, 17.61\%]$).
3. **Главный консервативный итог HARA (`Worst-Case Subclass`):** **Класс S2**
   * *Определение:* $S_{worst} = \max(S_A, S_B) = \max(S1, S2) = \mathbf{S2}$.
   * *Область применения:* В соответствии с **SAE J2980:2023 §5.2.1.5(g)** и **§5.2.2.2 Note 1** различные дорожные профили (жёсткое ограждение `1.1.A` и водоотводный кювет `1.1.B`) ведутся в HARA **раздельными строками** без разбавляющего усреднения тяжести весами ODD (веса $0.20$ и $0.80$ учитываются в экспозиции $E$). При сведении в единый консервативный вердикт сценария принимается $S_{worst} = \mathbf{S2}$. *(Справочный расчёт взвешенного пула ODD приведён в отдельной информационной строке таблицы Раздела 2 и не используется для назначения класса тяжести HARA.)*

### 1.2. Методологическое обоснование раздельных строк HARA (исключение Double Weighting Paradox)
В соответствии с **SAE J2980:2023 §5.2.1.5(g)** и **§5.2.2.2 Note 1** (а также ISO 26262-3 Clause 6) различные дорожные профили — жёсткое ограждение (`1.1.A`: **$S_A = S1$**, $P_A(\ge S2 \mid \text{ДТП}) = 1.6\%$) и водоотводный кювет (`1.1.B`: **$S_B = S2$**, $P_B(\ge S2 \mid \text{ДТП}) = 12.1\%$) — заносятся в таблицу HARA **раздельными строками**, поскольку доли дорожной инфраструктуры ($W_A = 0.20$, $W_B = 0.80$) уже учитываются в параметре экспозиции $E$ (исключение Double Weighting Paradox и разбавления тяжести). Главным сводным итогом HARA является консервативный класс наихудшего подкласса **$S_{worst} = \max(S1, S2) = S2$**. Для текущей выборки справочный взвешенный расчёт $0.20\cdot A + 0.80\cdot B$ численно совпадает с $S_{worst}$ ($S_{ODD,\text{справ.}} = S2$), однако не используется как критерий назначения.

### 1.3. Статистика реализации кинематического конфликта в слепой зоне (Pre-Crash Conflict Funnel)
* **Подкласс А (Ограждение слева):** Сгенерировано **200** стохастических сцен. Реализовано кинематических столкновений ($n_A$): **189** (94.5%). Безаварийных разъездов (Safe Pass): **11** (5.5%).
* **Подкласс B (Кювет справа):** Сгенерировано **200** стохастических сцен. Реализовано кинематических столкновений ($n_B$): **190** (95.0%). Безаварийных разъездов (Safe Pass): **10** (5.0%).
* **Суммарный ансамбль по ODD:** Из $N_{total} = 400$ стохастических прогонов состоялось **$N_{crash} = 379$ ДТП** (94.8%), **21 прогон** (5.2%) завершился безопасным опережением без физического контакта ТС.

**Физическая природа безаварийных разъездов (Safe Pass):**
В соответствии с ODD диапазон продольного смещения спавна Target (`Seat Leon`, $4.19\text{ м}$) относительно Ego (`Chevrolet Impala`, $5.36\text{ м}$) охватывает всю область перекрытия слепой зоны (`target_offset_y` от $-5.680$ до $-1.415\text{ м}$). При генерации Target в дальней кормовой части диапазона динамика перестроения Ego на скорости $100\text{ км/ч}$ ($27.78\text{ м/с}$) в ряде сцен позволяет Ego завершить смещение на смежную полосу с опережением и без физического контакта кузовов.

### 1.4. Статистическая неопределённость: 95% ДИ Клоппера–Пирсона для $P(\ge S2 \mid \text{ДТП})$ и анализ исходов $S3$
**1. Информационные 95% доверительные интервалы Клоппера–Пирсона для $P(\ge S2 \mid \text{ДТП})$ (`SAE J2980:2023 Appendix B §B.1`):**
Точный биномиальный 95% ДИ Клоппера–Пирсона приводится как **информационный индикатор статистической неопределённости конечной выборки** (при этом нормативная классификация выполняется по точечной оценке вероятности $> 10.0\%$, верхняя граница ДИ не является жёстким правилом стандарта):

* **Строка `1.1.A` (Подкласс А — ограждение):** $P_A(\ge S2 \mid \text{ДТП}) = \frac{3}{189} = 1.59\%$, $\text{CI}_{95\%} = [0.33\%, 4.57\%]$.
* **Строка `1.1.B` (Подкласс B — кювет):** $P_B(\ge S2 \mid \text{ДТП}) = \frac{23}{190} = 12.11\%$, $\text{CI}_{95\%} = [7.83\%, 17.61\%]$.

**2. Детальный анализ критических исходов $S3$ в Подклассе B (сход в кювет):**

* **Точечная оценка вероятности S3 при ДТП:** $P(S3 \mid \text{ДТП}) = \frac{4}{190} = 2.11\%$.
* **Точный 95% доверительный интервал:** $\text{CI}_{95\%} = [0.58\%, 5.30\%]$.

**Физико-статистическое заключение по S3:**
Верхняя граница 95% доверительного интервала (**5.30%**) лежит строго ниже порога **10.0%** (при точечной оценке $P(S3 \mid \text{ДТП}) = 2.11\%$). Это подтверждает низкую неопределённость исключения класса S3 для данного ODD. Все 4 заезда S3 зафиксированы по граничному условию на бровке $Y = 9.75\text{ м}$: 4 заезда критического бокового срыва (High-Speed Soil-Trip Rollover Risk).

## 3. СВОДНЫЙ ПРОТОКОЛ ПРИМЕНЕНИЯ ПРАВИЛА >10% (ISO 26262-3 / SAE J2980:2023)

Кумулятивная проверка порога репрезентативности $10.0\%$ проводится строго сверху вниз по выборке состоявшихся ДТП:
* **Строка HARA 1.1.A — Подкласс А (Ограждение слева) (выборка ДТП $n = 189$):**
  * $P(S3 \mid \text{ДТП}) = 0.0\%$ (95% ДИ: [0.00%, 1.93%]) $\le 10.0\%$, $P(\ge S2 \mid \text{ДТП}) = 1.6\%$ (95% ДИ: [0.33%, 4.57%]) $\le 10.0\%$ — пороги S3 и S2 не достигнуты.
  * Финальная отсечка на **Шаге 3**: $P(\ge S1 \mid \text{ДТП}) = 98.9\% > 10.0\%$ — порог преодолен на **+88.9%**.
  * **Итоговый вердикт:** **Класс S1**.

* **Строка HARA 1.1.B — Подкласс B (Кювет справа) (выборка ДТП $n = 190$):**
  * $P(S3 \mid \text{ДТП}) = 2.1\%$ (95% ДИ: [0.58%, 5.30%]) $\le 10.0\%$ — нормативный порог фатальных травм не достигнут.
  * Финальная отсечка на **Шаге 2**: $P(\ge S2 \mid \text{ДТП}) = 12.1\%$ (95% ДИ: [7.83%, 17.61%]) $> 10.0\%$ — порог преодолен с запасом **+2.1%**.
  * **Итоговый вердикт:** **Класс S2**.

* *Справочно (не используется для назначения класса тяжести HARA):* взвешенный пул ODD ($N_{crash} = 379$) даёт $P_{ODD}(S3 \mid \text{ДТП}) = 1.7\%$, $P_{ODD}(\ge S2 \mid \text{ДТП}) = 10.00\%$ (формально **S2**); по SAE J2980:2023 §5.2.1.5(g) и §5.2.2.2 Note 1 усреднение между разнородными дорожными условиями не допускается.
