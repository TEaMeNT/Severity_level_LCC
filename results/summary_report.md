## 1. РЕЗЮМЕ ОЦЕНКИ И ИТОГОВЫЕ ВЕРДИКТЫ ТЯЖЕСТИ (SEVERITY)

* **Исследуемый функциональный отказ:** Необнаружение попутного транспортного средства в слепой зоне при начале маневра перестроения на загородной автомагистрали ($100\text{ км/ч}$).
* **Общий объем стохастического ансамбля сценариев:** $N_{total} = 400$ прогонов (Подкласс А: $N_A = 200$, Подкласс С: $N_C = 200$).
* **Репрезентативная выборка состоявшихся ДТП (Accident-Involved Runs):** $N_{crash} = 217$ прогонов (Подкласс А: $n_A = 120$, Подкласс С: $n_C = 97$). Классификация тяжести последствий (Severity, S) по стандарту ISO 26262-3 / SAE J2980 выносится строго по данной выборке.

### 1.1. Многоуровневые вердикты по стандарту ISO 26262-3 / SAE J2980:
1. **Вердикт для Подкласса А (Отбойник слева, $n_A = 120$):** **Класс S2**
   * *Обоснование:* Кумулятивная вероятность тяжелых травм среди ДТП P(≥S2 | ДТП) = 38.3% (S3: 0.0%, S2: 38.3%) превышает нормативный порог 10.0%.
2. **Вердикт для Подкласса С (Кювет справа, $n_C = 97$):** **Класс S2**
   * *Обоснование:* Кумулятивная вероятность тяжелых травм среди ДТП P(≥S2 | ДТП) = 62.9% (S3: 3.1%, S2: 59.8%) превышает нормативный порог 10.0%.
3. **Консервативный вердикт по сценарию (Worst-Case Subclass):** **Класс S2**
   * *Определение:* $S_{worst} = \max(S_A, S_C) = \max(S2, S2) = \mathbf{S2}$.
   * *Область применения:* Используется при раздельном ведении подклассов дорожных условий в таблице HARA (где веса $0.20$ и $0.80$ уже учтены в классе Экспозиции $E$).
4. **Взвешенный вердикт по объединенному ODD (Пул ODD, $N_{crash} = 217$):** **Класс S2**
   * *Определение:* По условным взвешенным вероятностям $P_{ODD}(S_i \mid \text{ДТП}) = 0.20 \cdot P_A(S_i \mid \text{ДТП}) + 0.80 \cdot P_C(S_i \mid \text{ДТП})$.
   * *Обоснование:* Взвешенная кумулятивная вероятность среди ДТП P_ODD(≥S2 | ДТП) = 58.0% превышает нормативный порог 10.0%.

### 1.2. Разрешение парадокса весов ODD (Double Weighting Paradox)
Поскольку оба дорожных подкласса независимо демонстрируют доминирование тяжелых исходов $P(\ge S2 \mid \text{ДТП}) > 10.0\%$ (38.3% в отбойнике и 62.9% в кювете), консервативный вердикт по наихудшему сценарию ($S_{worst} = S2$) и взвешенный вердикт по пулу ODD ($S_{ODD} = S2$) полностью совпадают. В соответствии с ISO 26262-3 (Clause 6) в рабочую таблицу HARA подклассы заносятся раздельными строками для точного соотнесения с типами защитной инфраструктуры.

### 1.3. Статистика реализации кинематического конфликта в слепой зоне (Pre-Crash Conflict Funnel)
* **Подкласс А (Отбойник слева):** Сгенерировано **200** стохастических сцен. Реализовано кинематических столкновений ($n_A$): **120** (60.0%). Безаварийных разъездов (Safe Pass): **80** (40.0%).
* **Подкласс С (Кювет справа):** Сгенерировано **200** стохастических сцен. Реализовано кинематических столкновений ($n_C$): **97** (48.5%). Безаварийных разъездов (Safe Pass): **103** (51.5%).
* **Суммарный ансамбль по ODD:** Из $N_{total} = 400$ стохастических прогонов состоялось **$N_{crash} = 217$ ДТП** (54.2%), а **183 прогонов** (45.8%) завершились безопасным опережением без физического контакта ТС.

**Физическая природа безаварийных разъездов (Safe Pass):**
В соответствии с ODD диапазон продольного смещения спавна Target охватывает всю зону оптического и радарного перекрытия (`target_offset_y` от $-3.0$ до $-5.465$ м). При случайной генерации Target в дальней кормовой части слепой зоны динамика маневра перестроения ТС Ego на крейсерской скорости $100\text{ км/ч}$ ($27.78\text{ м/с}$) позволяет автомобилю Ego завершить смещение на смежную полосу с опережением и без физического пересечения габаритных объемов кузовов.

### 1.4. Детальный анализ критических исходов S3 и доверительные интервалы
Для оценки статистической репрезентативности фатальных и критических исходов $S3$ в Подклассе С (сход в кювет) проведен расчет точного 95% биномиального доверительного интервала Клоппера–Пирсона (Clopper–Pearson exact confidence interval):

* **Точечная оценка вероятности S3 при ДТП:** $P(S3 \mid \text{ДТП}) = \frac{3}{97} = 3.09\%$.
* **Точный 95% доверительный интервал:** $\text{CI}_{95\%} = [0.64\%, 8.77\%]$.

**Физико-статистическое доказательство нерепрезентативности S3:**
Верхняя граница 95% доверительного интервала (**8.77%**) строго не достигает нормативного порога **10.0%** (ISO 26262-3 / SAE J2980). Это статистически доказывает, что класс S3 является нерепрезентативным для данного ODD. Все 3 заезда S3 вызваны локальной потерей устойчивости на бровке откоса: 2 заезда опрокидывания (High-Speed Soil-Trip Rollover при углах заноса $\beta > 15^\circ$) и 1 заезд жесткого удара о дно кювета ($V_\perp > 12\text{ м/с}$).

### 5.3. Асимметрия уязвимости из-за соотношения масс ($m_{ego}/m_{tgt} = 1.75$)

При этом Target сносится с полосы в 97 случаях (48.5%), а Ego — в 96 случаях (48.0%). При этом в 1 заездах с полосы сошел только Target (в остальных 96 заездах в кювет сошли оба ТС).
