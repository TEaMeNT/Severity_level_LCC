### 1.1. Многоуровневые вердикты по стандарту ISO 26262-3 / SAE J2980:2023:
1. **Вердикт для Подкласса А (Ограждение слева, $n_A = 99$):** **Класс S1**
   * *Обоснование:* Кумулятивная вероятность травм легкой/средней тяжести среди ДТП P(≥S1 | ДТП) = 93.9% превышает нормативный порог 10.0%.
2. **Вердикт для Подкласса B (Кювет справа, $n_B = 100$):** **Класс S2**
   * *Обоснование:* Кумулятивная вероятность тяжелых травм среди ДТП P(≥S2 | ДТП) = 12.0% (S3: 4.0%, S2: 8.0%) превышает нормативный порог 10.0%.
3. **Консервативный вердикт по сценарию (Worst-Case Subclass):** **Класс S2**
   * *Определение:* $S_{worst} = \max(S_A, S_B) = \max(S1, S2) = \mathbf{S2}$.
   * *Область применения:* Используется при раздельном ведении подклассов дорожных условий в таблице HARA (где веса $0.20$ и $0.80$ уже учтены в классе Экспозиции $E$).
4. **Взвешенный вердикт по объединенному ODD (Пул ODD, $N_{crash} = 199$):** **Класс S2**
   * *Определение:* По условным взвешенным вероятностям $P_{ODD}(S_i \mid \text{ДТП}) = 0.20 \cdot P_A(S_i \mid \text{ДТП}) + 0.80 \cdot P_B(S_i \mid \text{ДТП})$.
   * *Обоснование:* Взвешенная кумулятивная вероятность среди ДТП P_ODD(≥S2 | ДТП) = 10.00% превышает нормативный порог 10.0%.

### 1.2. Разрешение парадокса весов ODD (Double Weighting Paradox)
Оба метода агрегации дают согласованный итоговый класс тяжести ($S_{worst} = S_{ODD} = S2$): в Подклассе А (ограждение) получено **$S_A = S1$** ($P(\ge S2 \mid \text{ДТП}) = 2.0\%$), в Подклассе B (кювет) — **$S_B = S2$** ($P(\ge S2 \mid \text{ДТП}) = 12.0\%$). В соответствии с ISO 26262-3 (Clause 6) в рабочую таблицу HARA подклассы заносятся раздельными строками (`1.1.A` и `1.1.B`), поскольку дорожные веса $W_A = 0.20$ и $W_B = 0.80$ уже учитываются в экспозиции $E$.
