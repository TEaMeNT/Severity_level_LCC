## 1. Прямой вердикт аудитора

### 1.1. Оценка гипотезы критика
1. **Тезис 1 (математический коллапс `S2` в `classify_ditch_boundary()`): ПОДТВЕРЖДЁН НА 100%.**
   В [runner.py](file:///c:/Users/teament/Desktop/xlam/Severity_level_LCC/runner.py#L266-L300) и её копии в [analyze_results.py](file:///c:/Users/teament/Desktop/xlam/Severity_level_LCC/analyze_results.py#L269-L294) условие `is_s3_skid` проверяет `v_lat_car > 5.5` внутри `is_non_tracking = (beta >= 15.0)` при `v_dep > 18.0 м/с`. Поскольку по определению ([runner.py](file:///c:/Users/teament/Desktop/xlam/Severity_level_LCC/runner.py#L822-L840)) $v_{\text{lat}} = V_{\text{dep}} \cdot \sin(\beta)$ (подтверждено на всех 105 сходах в `lcc_hara_results.csv`: $\max |v_{\text{lat}} - V_{\text{dep}}\sin\beta| = 0.0244\text{ м/с}$ только за счёт округления), для любого трассового вылета со скоростью $V_{\text{dep}} > 5.5 / \sin(15^\circ) = 21.25\text{ м/с}$ (`76.5 км/ч`) условие `beta >= 15.0°` **тригонометрически гарантирует `v_lat_car > 5.5 м/с`**. Одновременно в физике `Config F` ни один из 174 проездов бровки в Подклассе В не превысил $V_\perp = 7.96\text{ м/с}$ (`7.95 м/с` по CSV — порог `is_s2_bottom = (v_perp_road > 8.0)` недостижим). В результате область `S2 Moderate Rollover Risk` на трассовых скоростях **математически пуста** (`0` из `92 997` точек на сетке при $V_{\text{dep}} > 21.25,\ V_\perp \le 8.0$), а классификатор перепрыгивает из `S1` сразу в `S3` через искусственный разрыв шириной `0.38°` (`Run 155`: `beta = 14.9°, v_lat = 6.44 м/с -> S1` vs `Run 191`: `beta = 15.3°, v_lat = 6.43 м/с -> S3`).

2. **Тезис 2 (физический смысл `5.5 м/с` и соотношение `S2` vs `S3` при опрокидывании): ПОДТВЕРЖДЁН ПО СУЩЕСТВУ, С ВАЖНЫМ ИНЖЕНЕРНЫМ УТОЧНЕНИЕМ ПРОТИВ ЧРЕЗМЕРНОГО ЗАНИЖЕНИЯ ДО `S1`.**
   - Порог $V_{\text{lat}} \approx 12\text{–}13\text{ mph}$ (`5.4–5.8 м/с`, номинально `5.5 м/с` / `~20 км/ч`) из натурных испытаний Cooperrider et al. (`SAE 900366`, `SAE 980022`) — это физический минимум **инициации** грунтового опрокидывания (*soil-tripped rollover*), а **не порог `S3` (`>10% AIS 5–6`)** в терминах ISO 26262-3 / SAE J2980.
   - По прямым данным NASS-CDS (`Viano, Parenteau & Edwards, 2007`; `Digges & Eigen, 2006, PMC3217475 Table 2 & Table 5`; `Funk et al., 2012`), для **пристёгнутых** пассажиров легковых авто общий риск `MAIS 3+` при опрокидывании составляет **`4.0–4.3% ± 1.2%`** (`3.6% ± 1.1%` без выброса). При чистом одиночном опрокидывании (*Rollover as 1st Event*, `PMC3217475 Table 5`) **реальная частота травм `MAIS 3+F` (Injury Rate per 100 exposed)** составляет **`0.9%`** при `0` инверсиях (`12.5%` только при тяжёлой деформации о вертикальное препятствие) и **`1.0%`** при `1` инверсии (`Moderate: 1.9%`), возрастая до **`10.6%`** (`Moderate: 14.7%`) при **`2+` инверсиях**. Для опрокидываний с предшествующим ударом (*Table 2*) общий риск составляет `4.10%` (`Minor: 1.92%`, `Moderate: 3.51%`, `Severe: 10.26%`). Хотя сам первичный удар LCC ($\Delta V_{\text{tgt}} \le 2.34\text{ м/с}$) относится к `Minor/Moderate`, порог **`S2` (`>10% AIS 3–6`)** при $V_{\text{lat}} > 5.5\text{ м/с}$ на `~90 км/ч` в кювете `1V:4H` глубиной `1.20 м` обосновывается сочетанием: (а) `Table 5` для `2+` инверсий при высокой энергии выбега на обратный откос (`10.6%` у пристёгнутых), (б) требования `SAE J2980:2023 §B.4` (стр. 20) учитывать фактическую популяцию, включая непристёгнутых участников (`12.3–31.2%`), и (в) усугубления опрокидывания предшествующим плоским ударом (`ESV 231`). Напротив, переход в **`S3` (`>10% AIS 5–6`)** требует многооборотного высокоэнергетического срыва с критическим углом заноса, удара о твёрдое препятствие или лобового утыкания в откос.
   - **Критическое уточнение против занижения до `S1`:** если полностью убрать учёт критерия инициации триппинга ($V_{\text{lat}} > 5.5\text{ м/с}$) из `S2` и требовать для `S2` только $\beta \ge 20^\circ$ (`V4` в Разделе 4), доля $\ge S2$ падает до `5.0% -> S1`. Для кювета `1V:4H` глубиной `1.20 м` после бокового удара ТС–ТС это **преждевременно занижено** (особенно до устранения бага `static.trigger.friction` и перепрогона CARLA): при зарывании колёс в грунт на скорости $V_{\text{lat}} > 5.5\text{ м/с}$ (`1.23–1.62 g` по Cooperrider) на уклоне `14°` и перепаде `1.20 м` консервативная оценка риска `MAIS 3–6 > 10%` обоснованно соответствует **`S2`**.

    # S3 (MAIS 5-6 > 10%): широкоугольный высокоэнергетический срыв / мульти-инверсия (Digges 2+ инв., NCHRP 665 >=25° / быстрый разворот) или жёсткий упор носом

### 4.3. Достаточно ли пересчитать имеющиеся 200 прогонов или нужен перепрогон CARLA?
1. **Для исправления классификатора (`S3 -> S2`):** оффлайн-переклассификация `200` имеющихся прогонов **допустима как консервативная оценка сверху для `S2`**. Поскольку ранний триггер трения на асфальте (`Y = 5.6–6.3 м`) *завышал* угол заноса `beta` (`+1.74°` в среднем и `+4.04°` для `[15°, 20°)`), а `Runs 116, 153` содержат клиппинг-артефакты PhysX, очистка модели может лишь *уменьшить* или оставить на месте долю `S2/S3`.
2. **Для финальной научной валидации HARA перепрогон CARLA (как минимум `SubB` пассивная + парная активная кампания) НЕОБХОДИМ** после устранения дефектов симуляции в `runner.py`:
   - Заменить триггер `static.trigger.friction` с бокса `Y ∈ [7.50, 9.75] м` на по-осевое/корректно смещённое срабатывание по реальному контакту колёс с обочиной (`Y >= 7.50 м`) и **продлить зону пониженного трения до `Y = 30.0 м`**, устранив `EndOverlap` (`Y ≈ 11.49 м`) внутри кювета.
   - Проверить настройку **`use_sweep_wheel_collision`** и геометрию коллайдеров `Impala/Leon` для исключения raycast-наезда/выброса как в `Run 116 / 153` (и при необходимости уточнить массу `EGO_MASS = 3490 кг`, дающую отношение масс `~2.32×`).
   - Запустить согласованную кампанию `active` для расчёта **Controllability (`C`)** (причём правильное трение на обочине и исключение `Y >= 28.0 м` clamp-спайков критически важны для корректного контрруления).
