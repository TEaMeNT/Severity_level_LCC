### 1.1. Многоуровневые вердикты по стандарту ISO 26262-3 / SAE J2980:2023:
1. **Вердикт для Подкласса А (Ограждение слева, $n_A = 199$):** **Класс S1**
   * *Обоснование:* Кумулятивная вероятность травм легкой/средней тяжести среди ДТП P(≥S1 | ДТП) = 94.5% превышает нормативный порог 10.0%.
2. **Вердикт для Подкласса B (Кювет справа, $n_B = 198$):** **Класс S1**
   * *Обоснование:* Кумулятивная вероятность травм легкой/средней тяжести среди ДТП P(≥S1 | ДТП) = 92.4% превышает нормативный порог 10.0%.
3. **Консервативный вердикт по сценарию (Worst-Case Subclass):** **Класс S1**
   * *Определение:* $S_{worst} = \max(S_A, S_B) = \max(S1, S1) = \mathbf{S1}$.
   * *Область применения:* Используется при раздельном ведении подклассов дорожных условий в таблице HARA (где веса $0.20$ и $0.80$ уже учтены в классе Экспозиции $E$).
4. **Взвешенный вердикт по объединенному ODD (Пул ODD, $N_{crash} = 397$):** **Класс S1**
   * *Определение:* По условным взвешенным вероятностям $P_{ODD}(S_i \mid \text{ДТП}) = 0.20 \cdot P_A(S_i \mid \text{ДТП}) + 0.80 \cdot P_B(S_i \mid \text{ДТП})$.
   * *Обоснование:* Взвешенная кумулятивная вероятность среди ДТП P_ODD(≥S1 | ДТП) = 92.8% превышает нормативный порог 10.0%.

### 1.2. Разрешение парадокса весов ODD (Double Weighting Paradox)
Оба метода агрегации дают согласованный итоговый класс тяжести ($S_{worst} = S_{ODD} = S1$): в Подклассе А (ограждение) получено **$S_A = S1$** ($P(\ge S2 \mid \text{ДТП}) = 0.5\%$), в Подклассе B (кювет) — **$S_B = S1$** ($P(\ge S2 \mid \text{ДТП}) = 8.1\%$). В соответствии с ISO 26262-3 (Clause 6) в рабочую таблицу HARA подклассы заносятся раздельными строками (`1.1.A` и `1.1.B`), поскольку дорожные веса $W_A = 0.20$ и $W_B = 0.80$ уже учитываются в экспозиции $E$.

При этом Target сносится с полосы в 183 случаях (91.5%), а Ego — в 153 случаях (76.5%). При этом в 30 заездах с полосы сошел только Target (в остальных 153 заездах в кювет сошли оба ТС).
