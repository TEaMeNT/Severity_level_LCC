# Severity_level_LCC

**Симуляция HARA: отказ системы контроля слепых зон (LCC Blind Spot Failure) в CARLA Simulator**  
*Стандарты безопасности:* **ISO 26262-3 (HARA)** / **SAE J2980** (Appendix B — Severity, Appendix E — Driver Shock)

---

## 📌 Описание проекта

Исследовательский проект физически достоверного моделирования и оценки тяжести последствий (**Severity S0–S3**) при отказе функции удержания в полосе / контроля слепых зон (**Lane Centering Control / Blind Spot Detection**) при маневре перестроения на автомагистрали первой технической категории на скорости **100 км/ч (27.78 м/с)**.

Симуляция реализована в среде **CARLA Simulator (Unreal Engine 4 + NVIDIA PhysX)** с использованием предметно-ориентированного языка сценариев **Scenic** и охватывает два критических дорожных профиля:
1. **Подкласс А (`SUBCLASS_A_BARRIER`):** Маневр влево из полосы `-2` в `-1`. Слева от полосы `-1` ($Y \le 0.0$ м) расположен жесткий бетонный отбойник Нью-Джерси высотой $0.80$ м. Оценивается риск зажатия и вторичного соударения легкого автомобиля `Target` об ограждение.
2. **Подкласс С (`SUBCLASS_C_DITCH`):** Маневр вправо из полосы `-1` в `-2`. Справа от полосы `-2` расположены укрепленная гравийная обочина ($Y \in [7.50; 9.75)$ м) и 4-зонный водоотводный кювет с уклоном 1:4 ($Y \in [9.75; 20.85]$ м, $Z = -1.20$ м). Оценивается риск бокового зарывания колес (NHTSA Soil-Trip) и опрокидывания кузова (Rollover).

## 🚀 Быстрый запуск на любом ПК

### 1. Системные требования
* **ОС:** Windows 10/11 x64
* **Симулятор:** CARLA Simulator 0.9.14+ (по умолчанию в `C:\CARLA`)
* **Python:** 3.8–3.12 с установленными пакетами: `carla`, `scenic`, `numpy`

### 2. Установка карты в CARLA (выполняется один раз)
Скрипт автоматически скопирует скомпилированные карты `.umap` и меши `.uasset`/`.uexp` в директорию `Content` симулятора CARLA:

```bash
python install_map_to_carla.py
```
*(Если CARLA установлена в нестандартную папку, передайте параметр: `python install_map_to_carla.py --carla-dir "D:\CARLA"`)*

### 3. Запуск сервера CARLA
В отдельном окне терминала запустите симулятор:
```bash
C:\CARLA\CarlaUE4.exe
```

### 4. Запуск HARA кампании (`runner.py`)
```bash
# 1. Полномасштабная эталонная кампания (100 Подкласс А + 100 Подкласс С) в пассивном режиме:
python runner.py --runs 200 --mode equal --driver-post-shock passive --timestep 0.02 --seed 42 --clear

# 2. Исследование только Подкласса А (боковой удар и отбойник, 50 прогонов):
python runner.py --subclass A --runs 50 --timestep 0.02

# 3. Исследование только Подкласса С (съезд в кювет, 50 прогонов):
python runner.py --subclass C --runs 50 --timestep 0.02

# 4. Оценка управляемости (Controllability C): водитель активно парирует занос:
python runner.py --runs 200 --mode equal --driver-post-shock active --timestep 0.02 --seed 42

# 5. Запуск с отображением визуального окна CARLA для отладки:
python runner.py --subclass A --runs 2 --render
```

### 5. Статистический анализ и генерация отчетов (`analyze_results.py`)
После завершения симуляций выполните расчет классов тяжести по правилу `> 10%` (ISO 26262-3 / SAE J2980):
```bash
python analyze_results.py --input results/lcc_hara_results.csv --output-dir results
```
Команда формирует итоговый аналитический отчёт `results/summary_report.md` и 5 публикационных графиков (300 DPI) в папке `results/plots/`.

## ⚙️ Параметры командной строки

### 1. Параметры исполнителя симуляций (`runner.py`)

| Аргумент | Тип / Значения | По умолчанию | Описание и инженерный смысл |
| :--- | :--- | :---: | :--- |
| **`--subclass`** | `A`, `C`, `ALL` | `ALL` | **Дорожный подкласс сценария:**<br>• `A` (`SUBCLASS_A_BARRIER`) — маневр влево из полосы `-2` в `-1`, слева жесткий бетонный отбойник ($Y \le 0.0$ м).<br>• `C` (`SUBCLASS_C_DITCH`) — маневр вправо из полосы `-1` в `-2`, справа гравийная обочина и кювет 1:4 ($Y \in [9.75; 20.85]$ м, $Z = -1.2$ м).<br>• `ALL` — запуск смешанной исследовательской кампании. |
| **`--mode`** | `equal`, `sequential`, `weighted` | `equal` | **Стратегия распределения прогонов при `--subclass ALL`:**<br>• `equal` — **Равное распределение (50 / 50):** ровно $N/2$ прогонов для Подкласса А и $N/2$ для Подкласса С.<br>• `sequential` — **Детерминированная экспозиция:** 20% для Подкласса А и 80% для Подкласса С (сначала все А, затем все С).<br>• `weighted` — **Стохастическая экспозиция:** каждый прогон случайно выбирает подкласс с весами $P(A) = 0.20$ и $P(C) = 0.80$ (экспозиция E3). |
| **`--driver-post-shock`** | `passive`, `active` | `passive` | **Режим поведения водителя после фазы шока ($T_{\text{shock}}$):**<br>• `passive` — **Оценка тяжести Severity ($S$) по умолчанию:** водитель дезориентирован, педали газа и тормоза отпущены (`0.0`), накат с естественным сопротивлением качению и торможением двигателем, руль релаксирует кастором ($* 0.95$).<br>• `active` — **Активное парирование заноса (Controllability $C$):** агрессивное контрруление ($\le \pm 1.0$) и экстренное торможение в пол (`brake = 1.0` в опасных зонах). |
| **`--runs`** | `int` | `20` | **Общее количество запусков** сценария в кампании. |
| **`--timestep`** | `float` | `0.01` | **Шаг интегратора PhysX $dt$** в секундах (рекомендуется `0.02` для 50 Гц со стабильным substepping). |
| **`--seed`** | `int` | `42` | **Случайное зерно генератора PRNG** для строгой детерминированной воспроизводимости начальных сцен и времени задержки водителя. |
| **`--map-dir`** | `str` (путь к папке) | `None` (автопоиск) | Пользовательский путь к папке с картой OpenDRIVE `map_ditch.xodr`. По умолчанию проверяется `maps/assets`. |
| **`--clear`** | флаг | `False` | **Очистка файла результатов:** создает новый чистый CSV с записью заголовков колонок. |
| **`--render`** | флаг | `False` | **Окно визуализации:** включает графический рендеринг Unreal Engine. По умолчанию выключен (headless) для максимальной скорости симуляции. |

## 🔬 Ключевые инженерные решения и физика симуляции

1. **Когнитивная модель водителя и фаза шока (SAE J2980 Appendix E):**
   * Стохастическое время реакции водителя на удар $T_{\text{shock}} \sim \mathcal{N}(0.85, 0.12)$ в диапазоне $[0.65; 1.05]$ с.
   * Первые $0.25$ с смоделирован тонический спазм рук (руль удерживается в угле удара), затем руль релаксирует к нулю за счет угла кастора ($* 0.95$), педали сброшены.
2. **Двусторонний мониторинг столкновений (ISO 26262-3):**
   * Датчик коллизий установлен на оба автомобиля: `Ego` ($3490$ кг) и `Target` ($2000$ кг).
   * Регистрируется первичное боковое столкновение ТС–ТС с вычислением $\Delta V$ по закону сохранения импульса, а также вторичный контакт с бетонным отбойником Нью-Джерси.
   * Пространственный фильтр ($Y > 3.2$ м) исключает ложные срабатывания датчиков при касании разделительной разметки.
   * Окно съема скорости строго за 1 кадр до удара исключает преждевременное гашение скорости контактным солвером PhysX.
3. **Физическая модель обочины и террамеханики CARLA PhysX:**
   * Базовое сцепление шин с сухим асфальтом $\mu = 3.50$ задается один раз в Фазе 0 начальной конфигурации без вызовов в цикле `on_tick`, что исключает сброс пружин подвески PhysX.
   * Укрепленная гравийная обочина ($Y \in [7.50; 9.75)$ м) реализована через нативный триггерный объем CARLA `static.trigger.friction` ($\mu = 1.90$), который динамически переключает трение колес при пересечении границы и автоматически восстанавливает базовое сцепление при съезде.
4. **Анализ съезда в кювет на бровке $Y = 9.75$ м:**
   * Кинематический мониторинг фиксирует нормальную составляющую скорости $V_{\perp}$, угол наезда на откос, угол бокового увода $\beta$ и скорость рыскания $\omega_z$.
   * Классифицируются механизмы: Traversable Tracking Slope Departure, Hard Ditch Bottom Impact (Nose-In), Shallow Grazing Departure и боковое зарывание в грунт (NHTSA Soil-Trip Rollover).
