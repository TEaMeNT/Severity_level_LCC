# Severity_level_LCC

**Симуляция HARA: ложноотрицательный отказ пассивной системы контроля слепых зон при смене полосы (Lane Change Control, LCC / BSD — Blind Spot Failure) в CARLA Simulator**  
*Стандарты безопасности:* **ISO 26262-3:2018** (HARA, Clause 6, Annex B) / **SAE J2980:2023** (5.2.3 — Driver Behavior & Controllability, Appendix B — Severity)

---

## 📌 Описание проекта

Исследовательский проект физически достоверного моделирования и оценки тяжести последствий (**Severity S0–S3**) при отказе пассивной функции контроля слепых зон при смене полосы (**Lane Change Control, LCC / Blind Spot Detection** — пассивное информирование водителя индикаторами в зеркалах без вмешательства в управление) во время маневра перестроения на загородной автомагистрали на скорости **100 км/ч (27.78 м/с)**.

Моделируется столкновение защищаемого тяжёлого седана `Ego` (`vehicle.chevrolet.impala`, **3490 кг**) с попутным легковым автомобилем `Target` (`vehicle.seat.leon`, случайная масса по усечённому нормальному распределению `TruncatedNormal(1480, 220, [1100, 2050])` кг; $m_{ego}/m_{tgt} \in [1.70; 3.17]$).

Симуляция реализована в среде **CARLA Simulator (Unreal Engine 4 + NVIDIA PhysX)** с использованием предметно-ориентированного языка сценариев **Scenic** и охватывает два критических дорожных профиля:
1. **Подкласс А (`SUBCLASS_A_BARRIER`):** Маневр влево из полосы `-2` в `-1`. Слева от полосы `-1` ($Y \le 0.0$ м) расположено жёсткое вертикальное ограждение высотой $0.80$ м. Оценивается риск зажатия и вторичного соударения автомобилей с ограждением.
2. **Подкласс B (`SUBCLASS_B_DITCH`):** Маневр вправо из полосы `-1` в `-2`. Справа от полосы `-2` расположены укреплённая гравийная обочина шириной $2.25$ м ($Y \in [7.50; 9.75)$ м; консервативный профиль относительно ГОСТ 33475-2015 $3.0\text{–}3.5$ м) и водоотводный кювет с откосом 1:4 ($Y \in [9.75; 20.85]$ м, $Z = -1.20$ м). Тяжесть исходов оценивается методом граничных условий на бровке кювета $Y = 9.75$ м.

## 🚀 Быстрый запуск на любом ПК

### 1. Системные требования и установка пакета
* **ОС:** Windows 10/11 x64
* **Симулятор:** CARLA Simulator 0.9.14+ (по умолчанию в `C:\CARLA`)
* **Python:** 3.10–3.12 с установленными пакетами: `carla`, `scenic`, `numpy`, `scipy`, `matplotlib`, `pytest`
* **Локальная editable-установка пакета `hara-lcc`:**
```bash
python -m pip install --no-deps --no-build-isolation -e .
```

### 2. Установка карты в CARLA (выполняется один раз)
Скрипт автоматически скопирует скомпилированные карты `.umap` и меши `.uasset`/`.uexp` в директорию `Content` симулятора CARLA:

```bash
python install_map_to_carla.py
```
*(Если CARLA установлена в нестандартную папку, передайте параметр: `python install_map_to_carla.py --carla-dir "D:\CARLA"`)*

### 3. Запуск сервера CARLA
В отдельном окне терминала запустите симулятор:
```bash
C:\CARLA\CarlaUE4.exe
```

### 4. Калибровка сцепления и запуск HARA кампаний (`runner.py`)
```bash
# 0. Стендовая калибровка торможения (FrictionScale) на асфальте и гравийной обочине:
python test_shoulder_friction.py --timestep 0.01

# 1. Финальная кампания Severity S (200 Подкласс А + 200 Подкласс B) в пассивном режиме:
python runner.py --runs 400 --mode equal --driver-post-shock passive --timestep 0.01 --seed 42 --output results/lcc_hara_results.csv --clear

# 2. Исследование только Подкласса А (боковой удар и ограждение, 50 прогонов):
python runner.py --subclass A --runs 50 --timestep 0.01

# 3. Исследование только Подкласса B (съезд к бровке кювета, 50 прогонов):
python runner.py --subclass B --runs 50 --timestep 0.01

# 4. Кампания Controllability C (парная кампания с активным парированием заноса):
python runner.py --runs 400 --mode equal --driver-post-shock active --timestep 0.01 --seed 42 --output results/lcc_hara_active.csv --clear

# 5. Запуск с отображением визуального окна CARLA для отладки:
python runner.py --subclass A --runs 2 --timestep 0.01 --render

# 6. Выборочный реплей конкретных прогонов финальной кампании (--run-ids, быстрая перемотка PRNG):
python runner.py --runs 400 --mode equal --seed 42 --run-ids 220 --driver-post-shock passive --render --output scratch/replay_220.csv --clear
python runner.py --runs 400 --mode equal --seed 42 --run-ids 35,49,220,256,289,303 --driver-post-shock active --output scratch/replay_subset.csv --clear
```

### 5. Статистический анализ и генерация отчетов (`analyze_results.py`)
После завершения симуляций выполните расчет классов тяжести по правилу `> 10%` и управляемости `C` (ISO 26262-3 / SAE J2980:2023):
```bash
python analyze_results.py --input results/lcc_hara_results.csv --active-input results/lcc_hara_active.csv --output-dir results
```
Команда формирует итоговый аналитический отчёт `results/summary_report.md` и 5 публикационных графиков (300 DPI) в папке `results/plots/`.

### 6. Запуск оффлайн-автотестов (`pytest`)
Постоянный набор автотестов проверяет схему 25 колонок CSV, классификаторы `S0–S3` и Variant B (включая канонический датасет `v1.1-severity-final`, `N = 400`), изолированную модель водителя `src/hara_lcc/driver/`, статистику/ASIL/рендер отчёта, генерацию 5 графиков и оффлайн-сэмплирование сцен Scenic (`N = 500` на подкласс, `0` коллизий спавна) **без запущенной CARLA**:
```bash
python -m pytest -v
```

## 🔬 Ключевые инженерные решения и физика симуляции

1. **Модель реакции водителя и удержания управления (SAE J2980:2023 Section 5.2.3.2(d)):**
   * Применяется двухфазная стохастическая модель реакции: усечённо-логнормальная задержка реакции $T_{\text{react}} \in [0.65; 1.60]$ с (медиана $1.05$ с; Green 2000; Taoka 1989) и фаза кратковременного удержания руля в угле удара $T_{\text{hold}} \in [0.20; 0.35]$ с.
   * В течение $t \le T_{\text{hold}}$ удерживается доударный руль/газ (с принудительным сбросом газа у барьера или на бровке), при $T_{\text{hold}} < t < T_{\text{react}}$ педали сброшены и руль релаксирует (`* 0.95^(dt/0.01)`), а после $t \ge T_{\text{react}}$ в режиме `passive` накат продолжается, тогда как в режиме `active` контроллер удерживает раздельные целевые полосы для `Ego` и `Target` с лимитом скорости руля ($\le 2.5/\text{с}$), линейной рампой тормоза ($0.25$ с) и бортовой модуляцией торможения по кругу Камма и углу заноса `|beta|` (`kamm_steer * beta_scale`, без мировых координатных оракулов `loc_y`) в пределах горизонта симуляции **$45$ с ($4500$ тиков)**.
2. **Двусторонний мониторинг столкновений (ISO 26262-3):**
   * Датчик коллизий установлен на оба автомобиля: `Ego` (`vehicle.chevrolet.impala`, $3490$ кг) и `Target` (`vehicle.seat.leon`, `TruncatedNormal(1480, 220, [1100, 2050])` кг).
   * Регистрируется первичное боковое столкновение ТС–ТС с вычислением $\Delta V$ по закону сохранения импульса с фактической массой `Target` из `scene.params`, а также вторичный контакт с жёстким вертикальным ограждением $0.80$ м с учётом нормальной скорости строго внутрь барьера (`max(0.0, -v_inward_lr)` — отскок от стены не завышает тяжесть).
   * Пространственный фильтр (`loc_y > 3.5` м) исключает ложные срабатывания ударов о левое ограждение при манёврах в правую зону и Подклассе B.
   * Окно съема скорости строго за 1 кадр до удара исключает преждевременное гашение скорости контактным солвером PhysX.
3. **Калибруемый параметр `FrictionScale` шин, sweep-коллайдеры и EBD баланс тормозов (`Config F`):**
   * Безразмерный множитель сцепления PhysX `UTireConfig::FrictionScale` (не путать с классическим физическим коэффициентом трения $\mu$) задаётся на базовом асфальте значением `ASPHALT_TIRE_FRICTION_SCALE = 1.05` (~`0.81–0.86 g`) один раз в Фазе 0 до старта тиков; одновременно включается `use_sweep_wheel_collision = True` (исключение raycast-наездов колес) и задаётся пропорциональный EBD `max_brake_torque` (~65/35% перед/зад): `3800 / 2050 Н·м` для `Ego` (`3490 кг`) и `1.00 / 0.54 × target_mass` для `Target`.
   * Укреплённая гравийная обочина и кювет ($Y \ge 7.50$ м) реализованы через нативный триггерный объем CARLA `static.trigger.friction` с параметром `GRAVEL_TIRE_FRICTION_SCALE = 0.57` (~`0.46–0.48 g`; отношение `0.57 / 1.05 = 0.543`), левой границей бокса $Y = 8.50$ м (компенсация полуширины кузова под реальный выход колес на обочину) и правой границей $Y = 32.00$ м (без ложного `EndOverlap` на откосе кювета), и стендово верифицируются наземным тестом `test_shoulder_friction.py`.
4. **Метод граничных условий на бровке кювета $Y = 9.75$ м (Подклассы А и B, Вариант B):**
   * Кинематический мониторинг фиксирует полную скорость схода $V_{\text{dep}}$, нормальную составляющую $V_{\perp}$, боковую скорость кузова $V_{\text{lat}}$, угол бокового заноса $\beta$ и угловую скорость рыскания $\omega_z$ на границе проезжей обочины и начала откоса кювета для обоих подклассов (включая перекрёстные вылеты в Подклассе А).
   * Классифицируются механизмы со строгим вложением $S3 \Rightarrow S2 \Rightarrow S1$:
     * **S0** (`Shallow Grazing Departure`): низкоэнергетический касательный съезд ($V_{\text{dep}} \le 8.0$ или одновременно $V_{\perp} \le 2.0$, $V_{\text{lat}} \le 2.0$ и $\beta < 15^\circ$);
     * **S1** (`Traversable Tracking Slope Departure`): проходимый съезд по откосу `1:4` внутри предела AASHTO RDG Fig. 3-7 (`11.34 м/с`) либо умеренное скольжение ($V_{\text{dep}} > 8.0\text{ & }(V_{\perp} > 2.0 \text{ или } V_{\text{lat}} > 2.0)$ либо $\beta \ge 15^\circ$);
     * **S2** (`Moderate Rollover Risk` / `Hard Ditch Bottom Impact`): чистый порог грунтового опрокидывания Cooperrider (SAE 900366 / 980022) без ручного гейта $\beta \ge 15^\circ$ ($V_{\text{dep}} > 14.0\text{ & }V_{\text{lat}} > 5.5\text{ м/с}$), либо выраженный non-tracking срыв NCHRP 665 ($V_{\text{dep}} > 11.0\text{ & }\beta \ge 20^\circ$), либо выход за предел проходимости дна кювета AASHTO RDG ($V_{\text{dep}} > 8.0\text{ & }V_{\perp} > 12.0\text{ м/с}$);
     * **S3** (`High-Speed Soil-Trip Rollover` / `Severe Ditch Nose-In Impact`): критический широкоугольный срыв / быстрый спин ($V_{\text{dep}} > 18.0\text{ & }[\beta \ge 25^\circ \text{ или } (\beta \ge 20^\circ\text{ & }\omega_z > 45^\circ/\text{с})]$) либо экстремально крутой влёт $> 40^\circ$ на $100\text{ км/ч}$ ($V_{\text{dep}} > 8.0\text{ & }V_{\perp} > 18.0\text{ м/с}$).
5. **Управление Фазой 2 и правило `Safe Pass (1.0 с)` (исключение «фантомных `S0`»):**
   * Для `VehiclePIDController` автомобиля `Ego` (`3490 кг`) снят дефолтный лимит газа CARLA (`max_throttle = 1.0`, консервативный ПИД `lookahead = 25 м`, `~2.5 с`, `0.36 g` по SAE J2980 Table E2), при этом скорости и тяга `Ego` и `Target` до контакта остаются согласованными (`~100 км/ч`).
   * После завершения перестроения `Ego` в целевую полосу (`lane_id != start_lane_id`, `|y - y_center| <= 0.35 м`, `|v_y| <= 0.35 м/с`, `|yaw| <= 2.5°`) и удержания без столкновения в течение **$1.0\text{ с}$** фиксируется безопасный разъезд (`Safe Pass`) и у `Target` отключается слепой режим (`tm.ignore_vehicles_percentage(target, 0)`), что исключает искусственные догоняющие касания в задний бампер через `4–9 с` после манёвра.
