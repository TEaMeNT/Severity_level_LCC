# Severity_level_LCC

**Симуляция HARA: отказ системы контроля слепых зон (LCC Blind Spot Failure) в CARLA Simulator**  
*Стандарты безопасности:* **ISO 26262-3 (HARA)** / **SAE J2980** (Appendix B — Severity, Appendix E — Driver Shock)

---

## 📌 Описание проекта

Исследовательский проект физически достоверного моделирования и оценки тяжести последствий (**Severity S0–S3**) при отказе функции удержания в полосе / контроля слепых зон (**Lane Centering Control / Blind Spot Detection**) при маневре перестроения на автомагистрали первой технической категории на скорости **100 км/ч (27.78 м/с)**.

Симуляция реализована в среде **CARLA Simulator (Unreal Engine 4 + NVIDIA PhysX)** с использованием предметно-ориентированного языка сценариев **Scenic** и охватывает два критических дорожных профиля:
1. **Подкласс А (`SUBCLASS_A_BARRIER`):** Маневр влево из полосы `-2` в `-1`. Слева от полосы `-1` ($Y \le 0.0$ м) расположен жесткий бетонный отбойник Нью-Джерси высотой $0.80$ м. Оценивается риск зажатия и вторичного соударения легкого автомобиля `Target` об ограждение.
2. **Подкласс С (`SUBCLASS_C_DITCH`):** Маневр вправо из полосы `-1` в `-2`. Справа от полосы `-2` расположены укрепленная гравийная обочина ($Y \in [7.50; 9.75)$ м) и 4-зонный водоотводный кювет с уклоном 1:4 ($Y \in [9.75; 20.85]$ м, $Z = -1.20$ м). Оценивается риск бокового зарывания колес (NHTSA Soil-Trip) и опрокидывания кузова (Rollover).

## 🚀 Быстрый запуск на любом ПК

### 1. Системные требования
* **ОС:** Windows 10/11 x64
* **Симулятор:** CARLA Simulator 0.9.14+ (по умолчанию в `C:\CARLA`)
* **Python:** 3.8–3.12 с установленными пакетами: `carla`, `scenic`, `numpy`

### 2. Установка карты в CARLA (выполняется один раз)
Скрипт автоматически скопирует скомпилированные карты `.umap` и меши `.uasset`/`.uexp` в директорию `Content` симулятора CARLA:

```bash
python install_map_to_carla.py
```
*(Если CARLA установлена в нестандартную папку, передайте параметр: `python install_map_to_carla.py --carla-dir "D:\CARLA"`)*

### 3. Запуск сервера CARLA
В отдельном окне терминала запустите симулятор:
```bash
C:\CARLA\CarlaUE4.exe
```

### 4. Запуск HARA кампании
```bash
# 1. Эталонная кампания из 20 прогонов (10 Подкласс А + 10 Подкласс С) в режиме чистой Severity:
python runner.py --runs 20 --mode equal --driver-post-shock passive --clear

# 2. Исследование только Подкласса А (боковой удар и отбойник):
python runner.py --subclass A --runs 10

# 3. Исследование только Подкласса С (съезд в кювет и переворот):
python runner.py --subclass C --runs 10

# 4. Оценка управляемости (Controllability C): водитель парирует занос:
python runner.py --subclass C --runs 5 --driver-post-shock imperfect

# 5. Запуск с отображением визуального окна CARLA для отладки:
python runner.py --subclass A --runs 2 --render
```

## ⚙️ Параметры командной строки (`runner.py`)

| Аргумент | Тип / Значения | По умолчанию | Описание и инженерный смысл |
| :--- | :--- | :---: | :--- |
| **`--subclass`** | `A`, `C`, `ALL` | `ALL` | **Дорожный подкласс сценария:**<br>• `A` (`SUBCLASS_A_BARRIER`) — маневр влево из полосы `-2` в `-1`, слева жесткий бетонный отбойник ($Y \le 0.0$ м).<br>• `C` (`SUBCLASS_C_DITCH`) — маневр вправо из полосы `-1` в `-2`, справа гравийная обочина и кювет 1:4 ($Y \in [9.75; 20.85]$ м, $Z = -1.2$ м).<br>• `ALL` — запуск смешанной исследовательской кампании. |
| **`--mode`** | `equal`, `sequential`, `weighted` | `equal` | **Стратегия распределения прогонов при `--subclass ALL`:**<br>• `equal` — **Равное распределение (50 / 50):** ровно $N/2$ прогонов для Подкласса А и $N/2$ для Подкласса С.<br>• `sequential` — **Детерминированная экспозиция:** 20% для Подкласса А и 80% для Подкласса С (сначала все А, затем все С).<br>• `weighted` — **Стохастическая экспозиция:** каждый прогон случайно выбирает подкласс с вероятностями $P(A) = 0.20$ и $P(C) = 0.80$ (дорожная экспозиция E3). |
| **`--driver-post-shock`** | `passive`, `imperfect`, `active` | `passive` | **Режим поведения водителя после фазы шока ($T_{\text{shock}}$):**<br>• `passive` — **Оценка тяжести Severity ($S$) по умолчанию:** водитель дезориентирован, педали газа и тормоза отпущены (`0.0`), накат с естественным сопротивлением качению и торможением двигателем, руль релаксирует кастором ($* 0.95$).<br>• `imperfect` — **Несовершенная паническая реакция (SAE J2980):** водитель пытается спасти авто контррулением в целевую полосу ($\le \pm 0.35$) и умеренным торможением ($0.35$ на асфальте, $0.20$ на грунте) без полной блокировки колес.<br>• `active` — **Активное парирование заноса (Controllability $C$):** агрессивное контрруление ($\le \pm 1.0$) и экстренное торможение в пол (`brake = 1.0` в опасных зонах). |
| **`--runs`** | `int` | `20` | **Общее количество запусков** сценария в кампании. |
| **`--map-dir`** | `str` (путь к папке) | `None` (автопоиск) | Пользовательский путь к директории с файлом OpenDRIVE `map_ditch.xodr`. По умолчанию проверяется локальная папка `maps/assets`. |
| **`--clear`** | флаг | `False` | **Очистка файла результатов:** создает новый чистый `results/lcc_hara_results.csv` с заголовком. |
| **`--render`** | флаг | `False` | **Окно визуализации:** включает графический рендеринг. По умолчанию выключен (headless) для максимальной производительности (100 Гц). |

## 🔬 Ключевые инженерные решения и физика симуляции

1. **Когнитивная модель водителя и фаза шока (SAE J2980 Appendix E):**
   * Стохастическое время реакции водителя на удар $T_{\text{shock}} \sim \mathcal{N}(0.85, 0.12)$ в диапазоне $[0.65; 1.05]$ с.
   * Первые $0.25$ с смоделирован тонический спазм рук (руль удерживается в угле удара), затем руль релаксирует к нулю за счет угла кастора ($* 0.95$), педали сброшены.
2. **Двусторонний мониторинг столкновений (ISO 26262-3):**
   * Датчик коллизий установлен на оба автомобиля: `Ego` ($3490$ кг) и `Target` ($2000$ кг).
   * Регистрируется не только контакт между машинами, но и вторичный удар легкого `Target` о бетонный отбойник Нью-Джерси.
3. **6-режимная модель террамеханики в CARLA PhysX:**
   * Режим 1: сухой асфальт ($\mu = 3.50, C_{\text{lat}} = 20.0$).
   * Режим 2: боковой занос на асфальте после удара ($\mu = 2.45, C_{\text{lat}} = 18.0$).
   * Режим 3: гравийная обочина $[7.50; 9.75)$ м ($\mu = 1.90, f_r = 0.06$, исключено ложное закапывание).
   * Режим 4: наклонный откос кювета $1:4$ $[9.75; 14.55)$ м ($\mu = 1.25, f_r = 0.22$).
   * Режим 5: боковое зарывание в грунт кювета (Soil-Trip) с дифференциальным сцеплением колес ($3.20$ на опорных, $0.35$ на разгруженных), силами пахоты ($0.25g$), среза дерна ($0.35g$) и опрокидывающим моментом для Unreal Engine ($* 3500.0$).
   * Режим 6: возврат на асфальт (Road Recovery) с восстановлением $\mu = 3.50$.
4. **Устранение пробоев PhysX и оптимизация:**
   * Обертка `safe_apply_physics_control` кэширует поступательную и угловую скорости ТС при обновлении колес, устраняя баг обнуления импульса PhysX.
   * Защита от вылета за карту (`KillZ`) предотвращает падение кузова в пустоту за обратным откосом ($Y > 21.0$ м) и системный краш движка (`0xc0000409`).
   * Кэширование спектатора устранило блокирующие сетевые RPC-запросы на 100 Гц.

## 📊 Выходные данные (`results/lcc_hara_results.csv`)

Результаты каждого запуска логируются в файл с кодировкой UTF-8-SIG (для корректного открытия в Excel). Отчет содержит 20 параметров:
* Кинематику удара ($\Delta V_{\text{ego}}, \Delta V_{\text{target}}$ по закону сохранения импульса неравных масс 3490 кг и 2000 кг);
* Параметры удара об отбойник (скорость впечатывания, угол атаки, участник);
* Кинематику движения в кювете (скорость схода, скольжение, угол крена, 3D $\Delta V$ за 20 тиков, флаг зарывания колес);
* Итоговую категорию тяжести по стандарту ISO 26262-3 ($S0\dots S3$) и текстовое описание исхода.
